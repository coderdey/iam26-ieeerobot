find your devices on the desktop:

conda activate lerobot

# Find arm ports
lerobot-find-port   # repeat to find both arms

# Find cameras
lerobot-find-cameras opencv

Note the camera indices and native resolutions, then use this:

lerobot-record \
  --robot.type=so100_follower \
  --robot.port=/dev/ttyACM0 \
  --robot.id=follower_left \
  --robot.cameras="{ wrist: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, top: {type: opencv, index_or_path: 2, width: 1344, height: 376, fps: 30} }" \
  --teleop.type=so100_leader \
  --teleop.port=/dev/ttyACM1 \
  --teleop.id=leader_left \
  --dataset.repo_id=mithi/color-sort \
  --dataset.single_task="Pick colored object and place in matching bin" \
  --dataset.num_episodes=25 \
  --dataset.episode_time_s=30 \
  --dataset.reset_time_s=10 \
  --dataset.push_to_hub=false \
  --dataset.fps=30 \
  --display_data=true

What's different from the Acer settings:
- fps=30 — the desktop can handle it
- display_data=true — Rerun visualie rendering
- Two cameras — wrist + top (ZED 2)
- Linux ports — /dev/ttyACM0 and /dts (adjust based onlerobot-find-port output)

Before your first run, set USB permissions:
sudo chmod 666 /dev/ttyACM0 /dev/tt

Important: the camera index_or_pathely differ from the Acer. Runlerobot-find-cameras opencv first, note which index is the wrist webcam and which is the ZED 2 (the ZED will be the one with 1344x376 o and plug those numbers into thecommand.
