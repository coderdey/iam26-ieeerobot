Step 1: WSL2 + Ubuntu (Windows side)

Open PowerShell as Admin:
wsl --install -d Ubuntu-22.04
Restart, set up your Ubuntu username/password, then verify GPU passthrough works:
nvidia-smi
If that shows your GPU, you're good. If not, you need to install the NVIDIA CUDA driver for WSL (https://developer.nvidia.com/cuda/wsl) from the Windows side (not inside WSL).

Step 2: CUDA Toolkit (inside WSL)

# Add NVIDIA package repo
wget https://developer.download.nvidia.com/compute/cuda/repos/wsl-ubuntu/x86_64/cuda-keyring_1.1-1_all.deb
sudo dpkg -i cuda-keyring_1.1-1_all.deb
sudo apt-get update
sudo apt-get install cuda-toolkit-12-4

Step 3: Miniforge + conda env (inside WSL)

wget https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-x86_64.sh
bash Miniforge3-Linux-x86_64.sh
# restart shell, then:
conda create -n lerobot python=3.10 -y
conda activate lerobot

Step 4: PyTorch with CUDA (inside WSL)

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
# Verify:
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"

Step 5: LeRobot + Feetech SDK (inside WSL)

git clone https://github.com/huggingface/lerobot.git
cd lerobot
pip install -e ".[feetech]"

Step 6: ZED SDK (inside WSL)

Download from: https://www.stereolabs.com/developers/release — pick the Linux installer for your CUDA version (12.x). Then:
chmod +x ZED_SDK_Ubuntu22_cuda12.4_v4.*.run
./ZED_SDK_Ubuntu22_cuda12.4_v4.*.run
pip install pyzed

Important WSL caveat: ZED SDK in WSL needs USB passthrough. You'll need usbipd-win to forward the ZED 2 USB device into WSL:

On Windows (PowerShell Admin):
winget install usbipd

Then to attach the ZED 2 to WSL each time:
usbipd list                    # find the ZED 2 bus ID
usbipd bind --busid <BUS_ID>   # one-time
usbipd attach --wsl --busid <BUS_ID>  # each session

Inside WSL, verify:
lsusb  # should show Stereolabs ZED

Step 7: USB passthrough for servo controllers (same usbipd)

The Feetech servo controllers also need USB forwarding into WSL:
# On Windows, after plugging in both arm controllers:
usbipd list              # find both servo controller bus IDs
usbipd attach --wsl --busid <ARM1_BUS_ID>
usbipd attach --wsl --busid <ARM2_BUS_ID>

Inside WSL:
ls /dev/ttyACM*  # should show your arm ports
sudo chmod 666 /dev/ttyACM0 /dev/ttyACM1  # grant access

Step 8: Verify everything

conda activate lerobot

# GPU works
python -c "import torch; print(torch.cuda.is_available())"

# Arms accessible
lerobot-find-port

# ZED 2 accessible
python -c "import pyzed.sl as sl; cam = sl.Camera(); print('ZED OK')"

│  #  │          What          │  Where  │            Why             │
├─────┼────────────────────────┼─────────┼────────────────────────────┤

├─────┼────────────────────────┼─────────┼────────────────────────────┤

│ 3   │ CUDA toolkit 12.4      │ WSL     │ Training + ZED SDK         │
├─────┼────────────────────────┼─────────┼────────────────────────────┤
│ 4   │ usbipd-win             │ Windows │ USB devices into WSL       │
├─────┼────────────────────────┼─────────┼────────────────────────────┤
│ 5   │ Miniforge + conda      │ WSL     │ Python env management      │
├─────┼────────────────────────┼─────────┼────────────────────────────┤
│ 6   │ PyTorch + CUDA         │ WSL     │ Model training + inference │
├─────┼────────────────────────┼─────────┼────────────────────────────┤
│ 7   │ LeRobot + Feetech SDK  │ WSL     │ Arm control + recording    │

One gotcha: you'll need to usbipd attach the ZED and arm controllers every time you start a WSL session. It's a 10-second step but easy to forget.
