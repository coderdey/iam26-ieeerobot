Remote Desktop for Training

Before you leave the site today, set up SSH so you can train from home:

# On the desktop
sudo apt install openssh-ser
sudo systemctl enable ssh
sudo systemctl start ssh

# Note the desktop's IP
ip addr | grep inet

Then from your Acer at home:
ssh username@<desktop-ip>

If the desktop is behind a hwall, you may need:
- Tailscale (easiest — install on both machines, creates a VPN, free) — curl -fsSL
https://tailscale.com/instal
- Or port forwarding on the router

Once SSH works, you start training remotely with:
ssh username@desktop-ip
conda activate lerobot
python lerobot/scripts/train
  --dataset.repo_id=mithi/pick-place \
  --policy=act \
  --output_dir=outputs/train/pick-place-act

Use tmux or screen so training continues if your SSH disconnects:
sudo apt install tmux
tmux new -s train
# run training command insid
# Ctrl+B then D to detach
